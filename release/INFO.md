# Carpeta de Compilación (`release/`)

Esta carpeta contiene el archivo compilado y firmado listo para instalar en dispositivos Android TV / Kiosk (incluyendo Android 6.0+):

- **`ApexSignage-v1.0.apk`**: Archivo APK compilado y firmado (`com.aistudio.apexsignage.kptvxr`, versión `1.0`).
- **`output-metadata.json`**: Metadatos de compilación del paquete APK.
